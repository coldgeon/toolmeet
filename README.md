# U-Solve

실무자가 자신의 문서 업무를 설명하면 맞는 기존 AI 도구·워크플로를 찾고, 도입 조건과 실제 결과를 확인하도록 돕는 제품의 기획 저장소다. 현재는 인터뷰와 검증 가능한 완료 기준을 정리하는 단계이며 제품 코드나 실행 검증은 없다.

## 읽는 순서

1. [현재 상태](docs/CURRENT.md)와 [최근 인계](docs/HANDOFF.md)에서 확정·미정과 마감을 확인한다.
2. [제품 기획](docs/PRODUCT.md)과 [완료 기준](docs/ACCEPTANCE.md)을 대조한다.
3. [기업 업무 요청서](docs/INTAKE.md)와 [내부 시연 문서](docs/demo/README.md)를 참고한다.
4. 사용자 페르소나 담당 에이전트는 [작업 인계](docs/PERSONA_AGENT.md)를 먼저 읽는다.

`docs/reference/`의 과거 기획과 신청 원본, `docs/SETUP.md`의 개인 WSL 설정은 로컬 전용이다. Git 추적에서 제외하며, 과거 기획의 확정 표현보다 최근 사용자 발언과 `docs/CURRENT.md`를 우선한다. 가상 페르소나와 내부 시연 문서는 실제 고객 검증 자료가 아니다.

## 작업 범위

- 이번 단계: 제품 인터뷰, 후보 해법의 근거 확인, 검증 가능한 완료 기준.
- 제외: 제품 코드 구현, 배포, 유료 수집, Ralph 실행.
- 업무별 AI 도구 추천과 AI 소식 정리의 통합 여부는 미정이다.

작업 지침은 [AGENTS.md](AGENTS.md)에 있다. 비밀키와 로그인 정보는 저장소에 넣지 않는다.
