# U-Solve

실무자가 하려는 일을 말하면 저장된 솔루션 설명에서 관련 맥락을 찾고, 방법·전체 흐름 미리보기·원본 링크와 가이드까지 확인하는 U-Solve의 기획·로컬 시연 저장소다. 사용자는 이 탐색 방향을 승인했다. 프로토타입 시연의 상세와 2D·3D 작업별 사양은 별도 세션에서 정한다. 기본 화면은 공개 설명 요약·정적 확인 5건의 **로컬 키워드 검색**으로 동작한다. 대용량 저장소나 AI의 자유문장 이해, 기존 n8n 후보 설치, 실제 기업 문서와 PDF·Docs/Word·Excel·시트 파일 연동은 별도 검증 대상이다.

## 읽는 순서

1. [현재 상태](docs/CURRENT.md)와 [최근 인계](docs/HANDOFF.md)를 먼저 읽는다.
2. [제품 기획과 요청 형식](docs/PLAN.md), [완료 기준](docs/ACCEPTANCE.md)을 확인한다.
3. [탐색 시작 카탈로그](data/solutions.json)와 [내부 시연 입력](docs/demo/README.md), [사전 판정표](docs/demo/EXPECTED.md)를 시험 자료로 참고한다.
4. 페르소나 담당 에이전트는 [역할 인계](docs/PERSONA_AGENT.md)를 읽는다.

`docs/reference/`의 과거 기획과 신청 원본, `docs/SETUP.md`의 개인 WSL 설정은 로컬 전용이다. Git 추적에서 제외하며, 과거 기획의 확정 표현보다 최근 사용자 발언과 `docs/CURRENT.md`를 우선한다. 가상 페르소나와 내부 시연 문서는 실제 고객 검증 자료가 아니다. 이전 상세 문서와 판정 ID는 Git 커밋 `d5c6f78`에서 확인할 수 있다.

## 로컬 시연

기본 탐색 화면에는 Python 3.12 이상만 필요하다. 기존 `/demo`의 실제 본문 처리에는 별도로 로그인된 Codex CLI가 필요하다. 서버는 `127.0.0.1`에서만 열린다.

```bash
python3 app.py
```

탐색 흐름의 로컬 검증은 `python3 -m unittest discover -s tests -v`로 실행한다. 이 검증은 외부 AI 호출 없이 저장된 카드와 단계 경계만 확인한다.

브라우저에서 `http://127.0.0.1:8765`를 열어 하려는 일을 자유 문장으로 적는다. 저장된 카드의 원본 설명 단계와 U-Solve가 제안하는 미검증 보완 단계를 구분해 보고, 현재 로컬 구현의 2D 과정도를 확인한다. 이 과정도는 참고 구현이며 제품의 2D·3D 사양은 아니다. 방향 확인과 외부 AI 사용 가능 여부 확인 뒤에만 원본 URL과 준비 조건을 받는다. `불가/모름`이면 외부 AI 후보의 URL을 보류하고, 확인되지 않은 입력·출력 형식은 근거 확인만 안내한다. 이 기본 화면은 문서를 외부로 보내거나 공급자 워크플로를 실행하지 않는다.

기존 세 고정 사례의 본문 처리 시연은 `http://127.0.0.1:8765/demo`에 남아 있다. 방향 승인 뒤 `.md`·`.txt` 파일·붙여넣기와 문서별 공개·합성 자료 확인·Codex 전송 허용을 받는다. Codex CLI는 로그인된 계정의 외부 모델 서비스를 이용할 수 있으며 실제 공급자·모델·요금은 이 앱에서 확인하지 못한다. **기업 원본 문서는 넣지 않는다.** 결과의 원문 인용과 경고는 사람이 검토한다.

세 사례의 원본·변경 복사본을 다시 시험하려면 다음 명령을 쓴다. 이 명령은 **실제 Codex 호출 여섯 번**을 실행하며, 저장되는 자료는 `docs/demo/`의 공개·가상 입력뿐이다.

```bash
python3 scripts/verify_demo.py --save docs/demo/RUNS.json
```

## 작업 범위와 상태

- 2026-10-12 22:00(Asia/Seoul) 세 문서 사례 시연은 기존 목표다. 자동 사전 점검 증거는 있으나 사람의 원문 대조와 웹 화면 검토가 남아 전체 판정은 대기 중이다. 최신 방향 승인과 별도로 [현재 상태](docs/CURRENT.md)에 기록한다.
- 대용량 저장소와 대화형 AI 응답은 제품 목표다. 현재 5건 검색의 정확도·확장성은 아직 검증하지 않았다.
- PDF·Docs/Word·Excel·시트의 추가 실제 파일 입출력 조합은 미정이며 파일별 지원을 주장하지 않는다. 배포·유료 수집·Ralph 실행은 하지 않는다.
- 업무별 AI 도구 추천과 AI 소식 정리의 통합 여부는 미정이다.

작업 지침은 [AGENTS.md](AGENTS.md)에 있다. 비밀키와 로그인 정보는 저장소에 넣지 않는다.
