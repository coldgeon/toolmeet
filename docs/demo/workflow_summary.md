# 공개 워크플로 설명 A: URL·텍스트·PDF 요약

- 자료 종류: 공개 소개 페이지를 바탕으로 작성한 시험용 요약 문서.
- 공개 출처: [n8n의 워크플로 소개 페이지](https://n8n.io/workflows/8210-summarize-content-from-urls-text-and-pdfs-using-openai/).
- 확인 날짜: 2026-10-11.
- 작성 방식: 페이지의 기능·준비 조건을 요약했다. 실제 실행은 확인하지 않았다.

이 소개 페이지는 URL, 직접 입력한 텍스트, PDF를 다루는 별도 워크플로와 입력 종류에 따라 분기하는 통합형 워크플로를 설명한다. PDF는 텍스트 추출을 먼저 시도하고, 이미지 PDF는 OCR.Space를 대체 경로로 사용한다고 적혀 있다. 결과는 Markdown 형식의 요약으로 반환한다고 설명한다.

준비 조건으로 n8n 인스턴스와 OpenAI 또는 OpenRouter 키가 제시된다. PDF 대체 경로에는 OCR.Space 키가 언급된다. 페이지가 말하는 `Use for free`는 전체 운영 비용이 무료라는 검증 결과가 아니다.

**미확인:** 여러 문서를 합쳐 하나의 요약 보고서를 만드는지, 한국어 결과 품질, 실제 비용, 계정·권한, 설치 성공 여부. U-Solve의 다중 문서 보고서 작업에 그대로 맞는다고 판정하지 않는다.
