# 공개 워크플로 설명 C: 양식 기반 PDF 생성

- 자료 종류: 공개 소개 페이지를 바탕으로 작성한 시험용 요약 문서.
- 공개 출처: [n8n의 워크플로 소개 페이지](https://n8n.io/workflows/5808-create-custom-pdf-documents-from-templates-with-gemini-and-google-drive/).
- 확인 날짜: 2026-10-11.
- 작성 방식: 페이지의 기능·준비 조건을 요약했다. 실제 실행은 확인하지 않았다.

이 소개 페이지는 Google Drive에 있는 Google Docs 양식을 찾아 필수 입력값을 질문하고, 누락 항목을 확인한 뒤 양식을 복사해 값을 채우고 PDF 링크를 전달하는 흐름을 설명한다. Google Apps Script가 양식의 자리 표시자를 채우는 단계로 안내된다.

준비 항목에는 Google Drive·Docs 권한, LLM 키, Apps Script 배포가 있다. 페이지 상단은 커뮤니티 노드 때문에 자체 호스팅에서만 호환된다고 안내하지만, 본문에는 클라우드에서도 작동한다는 문장도 있다. 호스팅 조건은 원문 안에서 표현이 엇갈리므로 확인이 필요하다.

**미확인:** 실제 설치·실행, 무료 범위, 양식 파일 종류별 지원, 근거 정보가 없는 필드의 처리. U-Solve의 `주어진 양식에 맞는 초안` 작업에 직접 쓸 수 있다고 판정하지 않는다.
