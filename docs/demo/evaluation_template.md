# 자동화 후보 평가 양식

**시험을 위해 U-Solve가 작성한 빈 양식이다. 외부 기관의 공식 양식이 아니다.**

1. 해결하려는 문서 작업:
2. 후보 이름과 한 줄 설명:
3. 입력과 출력:
4. 필요한 계정·권한·실행 환경:
5. 비용 또는 무료 범위의 확인 수준:
6. 그대로 사용 / 일부 변경 / 적합성 미확인 중 판정과 이유:
7. 바꿔야 하는 단계가 있다면 해당 단계와 근거:
8. 공개 근거 URL과 확인 날짜:
9. 실제 실행 확인 여부:
10. 남은 질문:

정보가 없는 항목은 추정해 채우지 않고 `미확인` 또는 `확인 필요`로 적는다.
