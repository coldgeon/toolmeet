# 시연 입력 문서 세트

이 폴더는 내부 검증을 위한 선택적 시험 문서 세트다. 기업의 첫 문의 형식은 [제품 기획](../PLAN.md#실무자가-요청하는-형식)에 있다. 제품 코드나 실행 결과가 아니다. 공개 페이지에서 확인한 내용은 짧게 다시 쓰고 출처를 연결했다. `mock_meeting.md`의 회의와 결정은 전부 시험용 가상 상황이다. [사전 판정표](EXPECTED.md)는 사람이 결과를 대조할 기대 사실과 변경 반례이며 제품에 넣을 정답 데이터가 아니다.

| 검증 사례 | 입력 문서 | 검증할 결과 |
|---|---|---|
| 여러 문서 요약 | `workflow_summary.md`, `workflow_meeting.md`, `workflow_template.md` | 세 문서의 차이와 공통 조건을 출처와 함께 정리한 보고서 |
| 회의록 정리 | `mock_meeting.md` | 결정과 할 일의 분리, 담당자·기한이 없는 항목의 미확인 표시 |
| 정해진 양식의 초안 | `evaluation_template.md`와 위 워크플로 설명 문서 중 하나 | 양식 항목에 맞는 초안, 근거가 없는 비용·실행 여부의 미확인 표시 |

문서의 제목이나 미리 작성한 기대 답변만 사용해서는 통과할 수 없다. 실제 파일 본문을 읽어 결과를 만들고, 본문을 바꾸면 결과도 바뀌어야 한다. 이 세트만으로 사용자 원본 문서, 공급자 워크플로의 설치·동작, 저비용 조건은 검증되지 않는다.

공개 출처의 설명과 실제 실행 확인은 다르다. 여기 적은 워크플로는 후보이며 그대로 사용 가능 판정을 받지 않았다. 확인 날짜는 2026-10-11이다.
