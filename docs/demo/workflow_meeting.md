# 공개 워크플로 설명 B: 회의록의 결정·할 일 정리

- 자료 종류: 공개 소개 페이지를 바탕으로 작성한 시험용 요약 문서.
- 공개 출처: [n8n의 워크플로 소개 페이지](https://n8n.io/workflows/5904-transform-meeting-notes-into-action-items-with-gemini-and-google-workspace/).
- 확인 날짜: 2026-10-11.
- 작성 방식: 페이지의 기능·준비 조건을 요약했다. 실제 실행은 확인하지 않았다.

이 소개 페이지는 웹훅으로 회의 메모와 제목·참석자·날짜·시간 정보를 받아 Gemini로 요약, 결정, 할 일, 후속 조치를 추출하는 흐름을 설명한다. 이어 Google Tasks에 할 일을 만들고 Gmail로 후속 메일을 보내며 Google Docs에 회의 요약을 만든다고 적혀 있다.

페이지 상단에는 커뮤니티 노드가 포함돼 자체 호스팅한 n8n에서만 호환된다는 안내가 있다. 설정 항목에는 n8n 인스턴스, Google 서비스의 OAuth 자격 증명과 API 접근 권한이 포함된다.

**미확인:** 실제 설치·실행, 한국어 회의록의 정확도, 담당자·기한이 없는 경우의 처리, 계정별 비용. U-Solve에서 필요한 `결정·할 일만 정리` 작업보다 외부 서비스 연결이 넓어 그대로 사용 가능하다고 판정하지 않는다.
