# 가상 회의록: 문서 자동화 후보 검토

**시연용으로 만든 가상 회의다. 실제 회의·실제 협업자의 결정이나 업무 지시가 아니다.**

- 가상 날짜: 2026-10-11.
- 가상 참석자: 평가 담당 A, 평가 담당 B.
- 검토 자료: `workflow_summary.md`, `workflow_meeting.md`, `workflow_template.md`.

평가 담당 A는 URL·텍스트·PDF 요약 후보의 공개 설명을 보았다. 이 페이지에는 여러 입력 유형이 나오지만, 여러 문서를 한 보고서로 합치는 기능은 확인되지 않았다. 평가 담당 B는 회의록 후보에 Google Tasks·Gmail·Docs 연결이 포함돼 있음을 확인했다. 양식 후보는 Google Docs와 Apps Script가 필요하며, 공개 페이지의 자체 호스팅 조건 설명이 서로 달랐다.

**가상 결정:** 세 후보를 검토 목록에 남기되, 실행 전에는 어느 것도 `그대로 사용 가능`으로 표시하지 않는다. 시연용 평가 양식에는 확인되지 않은 비용과 실제 실행 상태를 `미확인`으로 적는다.

**가상 할 일:** 평가 담당 A는 2026-10-12까지 요약 후보가 복수 문서 보고서를 만들 수 있는지 확인한다. 평가 담당 B는 회의록 후보의 필수 권한을 정리한다. 양식 후보의 호스팅 조건은 추가 확인이 필요하지만 담당자와 기한은 정하지 않았다.

위 후보에 관한 설명의 출처는 각 검토 자료에 적었다. 이 회의의 발언, 결정, 할 일은 시험을 위해 작성한 내용이다.
