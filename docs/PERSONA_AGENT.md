# 페르소나 담당 에이전트 인계

이 문서는 별도 작업 트리에서 활동할 사용자 페르소나 담당 에이전트를 위한 작업 시작점이다. 사용자는 [제품 기획](PLAN.md)의 흐름을 이 에이전트와 주고받으며 검토하도록 지정했다. 기존 `38명 B2B 회사 운영팀장`은 **내부 합성 검증 사례**일 뿐 실제 고객 정체나 확인된 시장 수요가 아니다. 별도 작업 트리의 QA 초안은 main에 아직 병합되지 않았다.

## 먼저 확인할 자료

1. `AGENTS.md`, `docs/CURRENT.md`, `docs/HANDOFF.md`를 읽는다.
2. `docs/PLAN.md`, `docs/ACCEPTANCE.md`, `docs/demo/EXPECTED.md`를 읽는다.
3. `docs/reference/`는 과거 원자료로서 기본 작업 트리에는 포함되지 않을 수 있다. 최신 결정으로 취급하지 않는다.

## 맡을 일

- 사용자가 지정한 페르소나의 실제 업무, 현재 처리 방식, 원하는 결과를 구체적인 요청으로 정리한다.
- 문서 원본·출력·권한·외부 전송·비용·사람 검토 조건에서 빠진 결정을 지적한다.
- U-Solve의 추천·시뮬레이션·실제 시험 흐름에서 이해되지 않거나 적용할 수 없는 지점을 반례로 제시한다.
- 실제 사용자에게서 받은 사실, 사용자가 지시한 가정, 에이전트가 만든 가정을 별도 상태로 표시한다.
- 제품 범위의 최종 결정이나 외부 도구 실행 승인은 하지 않는다. 이 작업 트리 안에서만 정리하고 부모 작업에 변경 내용과 근거를 전달한다.

현재 사용자의 지시는 기획과 검증 기준까지다. 제품 코드 구현, 배포, 유료 수집, Ralph 실행은 시작하지 않는다.
