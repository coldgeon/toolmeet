## 현재 결정

- 사용자가 승인한 방향은 **하려는 일 자유 서술 → 저장된 솔루션 맥락 검색 → 근거 있는 방법 → 전체 흐름 미리보기 → 방향 확인 → 원본 링크·가이드 안내**다. 실제 도구·계정 연결과 대표 문서 첫 시험, 반복 적용은 각각 별도 단계다.
- 프로토타입 시연의 상세와 2D·3D 표현·작업 분해는 별도 세션에서 업무별로 정한다. 현재 로컬 2D 과정도는 참고 구현이다. AI 소식 정리와의 통합도 미정이다.
- 후보가 보류되면 이유와 다음 확인 행동·확인 주체·필요 근거를 남긴다. 링크 안내만으로 AX 도입 완료라고 표시하지 않는다.

## 현재 산출물과 검증 경계

- 기본 `/`는 [5건의 공개 설명 요약·정적 확인 카드](../data/solutions.json)를 로컬 키워드로 찾는다. 대용량 저장소, AI의 의도 이해, 원본 URL 현행성, 회사 적합성, 실제 도구 연결을 입증하지 않는다. 기존 세 문서 사례의 본문 처리 시연은 `/demo`에 보존했다.
- 기본 탐색 흐름의 `python3 -m unittest discover -s tests -v` **5개 시험**, 두 JS 파일의 `node --check`, Python 구문 검사와 `git diff --check`가 통과했다. 브라우저 직접 조작 검토는 남았다.
- 기존 세 사례는 공개 설명·합성 Markdown의 원본과 변경본 **여섯 실행 자동 사전 점검**을 통과했다. [RESULTS.md](demo/RESULTS.md)와 [RUNS.json](demo/RUNS.json)에 증거가 있다. 사람의 전체 원문 대조와 웹 화면 검토는 대기다. 2026-10-12 22:00 세 사례 목표는 보존하며 새 방향 승인으로 시연 PASS를 선언하지 않는다.
- 실제 PDF·Docs/Word·Excel·시트 파일 연동, 기업 원본 처리, n8n 설치, 반복 AX 효과는 미검증이다. GitHub 원격·배포·유료 수집·Ralph 실행은 없다. 가상 실무자 검토는 내부 합성 시나리오이며 실제 고객 검증이 아니다.
