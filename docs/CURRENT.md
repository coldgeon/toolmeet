# U-Solve 현재 상태

기준일: 2026-10-12, Asia/Seoul.

- 이번 프로토타입의 중심은 **박찬건 방향의 실무자 문서 업무 해결**이다. 새 기본 화면 `/`는 사용자의 자유 서술→저장된 솔루션 설명 검색→방법·근거→원본/제안 단계를 분리한 2D 시뮬레이션→방향 확인→원본 링크·방법 안내 순서다. [PLAN.md](PLAN.md)가 기획 기준, [ACCEPTANCE.md](ACCEPTANCE.md)가 판정 기준이다. 김성원 방향의 AI 소식 정리와의 통합은 미정이다.
- 현재 저장된 설명은 **5건**의 공개 설명 요약·코드 정적 확인이다. 로컬 키워드 검색이며 대용량 저장소, AI의 자유문장 이해, 현재 공개 URL 재검증, 회사 적합성 판정은 아직 없다. 무매치는 저장된 검색어 불일치로 표시한다. 감지한 외부 AI 금지 문장은 후보 시뮬레이션에서 제외하고, 연결 직전 별도 정책 확인에서 `불가/모름`이면 외부 AI 후보 URL을 제공하지 않는다. 확인되지 않은 PDF 입력·Excel 출력은 연결 보류로 표시한다.
- 이전 세 고정 사례의 본문 처리 화면은 `/demo`에 보존했다. 2026-10-12 22:00(Asia/Seoul) 전 목표는 여러 문서 요약, 회의록 후속 조치, 양식 초안 **세 사례 모두** 실제 입력 본문→결과물을 보여주는 것이다. 내부 합성·공개 설명 Markdown의 원본·변경본 여섯 실행은 [자동 사전 점검](demo/RESULTS.md)을 통과했다. 사람의 전체 원문 대조와 두 화면의 브라우저 조작 검토는 대기다.
- `/`는 실제 문서·외부 AI 모델을 사용하지 않는다. `/demo`는 공개·합성 시험 자료 확인과 문서별 전송 허용 뒤 Codex를 호출한다. 공급자·모델·요금·권한이 확인되지 않아 기업 원본은 시연 범위 밖이다. 실제 n8n 연결, PDF·Docs/Word·Excel·시트 파일 연동, 기업 AX 효과는 미검증이다.
- 내부 합성 페르소나와 독립 기획 검증자의 검토는 실제 고객 인터뷰가 아니다. `agent/persona-intake`와 `질문` 별도 작업 트리의 미병합 변경은 보존한다. GitHub `seongwwww/u-solve` 원격은 인증·원격 부재로 생성·푸시되지 않았다.
